# Security policy

## Supported versions

Security fixes are made on the latest release and the current development line.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Report it privately through GitHub's
"Report a vulnerability" (private security advisory) on this repository, or by email to the maintainer address listed
in `pyproject.toml`. Include the affected version, the steps to reproduce, and the impact you expect.

You will receive an acknowledgement, and the fix will be disclosed together with a release.

## Scope

Urdyn is a local library and CLI. See [docs/security-and-privacy.md](docs/security-and-privacy.md) for what it does
and does not protect.
